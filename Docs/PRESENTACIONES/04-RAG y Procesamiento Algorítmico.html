TEMA 2

HttpClient en .NET

La clase fundamental para comunicación HTTP. Aprender a usarla correctamente es la diferencia entre una aplicación robusta y una que falla en producción.

El Problema: Socket Exhaustion

Instanciar new HttpClient() en cada petición agota los sockets del sistema operativo. Cada instancia mantiene una conexión TCP abierta durante 4 minutos después de ser desechada.

La Solución: IHttpClientFactory

Patrón oficial de Microsoft. Gestiona un pool de conexiones, recicla sockets y permite configuración centralizada de timeouts, headers y políticas de reintento.

Configuración de Timeouts

Los modelos locales pueden tardar varios segundos en responder. Configurar timeouts apropiados (30-120s) evita fallos prematuros sin bloquear la aplicación indefinidamente.

Patrón Recomendado en .NET

Program.cs - Configuración de IHttpClientFactory 
// 1. Registrar el cliente HTTP en el contenedor de DI
builder.Services.AddHttpClient<IAiService, AiService>("OllamaClient", client =>
{
    client.BaseAddress = new Uri("http://localhost:11434");
    client.Timeout = TimeSpan.FromSeconds(120); // Timeouts generosos para inferencia local
    client.DefaultRequestHeaders.Accept.Add(
        new MediaTypeWithQualityHeaderValue("application/json"));
});

// 2. Implementación del servicio
public class AiService : IAiService
{
    private readonly HttpClient _client;

    public AiService(HttpClient client)
    {
        _client = client;
    }

    public async Task<ChatResponse> SendChatAsync(ChatRequest request)
    {
        var response = await _client.PostAsJsonAsync("/api/chat", request);
        response.EnsureSuccessStatusCode();
        return await response.Content.ReadFromJsonAsync<ChatResponse>();
    }
}
TEMA 3

Serialización con System.Text.Json

El serializador nativo de .NET. Rápido, seguro y con soporte para records inmutables.

✓ Tipado Fuerte

Records inmutables que garantizan la estructura del payload en tiempo de compilación.

✓ Naming Policy

Convierte automáticamente PropertyName a property_name (camelCase/snake_case).

✓ Utf8JsonReader/Writer

API de bajo nivel para streaming de JSON sin cargar todo el documento en memoria.

Models.cs - Records tipados 
// Records inmutables para el payload
public record ChatMessage(
    [JsonPropertyName("role")] string Role,
    [JsonPropertyName("content")] string Content);

public record ChatRequest(
    [JsonPropertyName("model")] string Model,
    [JsonPropertyName("messages")] List<ChatMessage> Messages,
    [JsonPropertyName("stream")] bool Stream = false);

public record ChatResponse(
    [JsonPropertyName("model")] string Model,
    [JsonPropertyName("message")] ChatMessage Message,
    [JsonPropertyName("done")] bool Done);
Uso de JsonSerializer 
var options = new JsonSerializerOptions
{
    PropertyNamingPolicy = JsonNamingPolicy.SnakeCaseLower,
    WriteIndented = false,
    DefaultIgnoreCondition = 
        JsonIgnoreCondition.WhenWritingNull
};

// Serializar
var json = JsonSerializer.Serialize(
    request, options);

// Deserializar desde stream (eficiente)
using var stream = await response.Content
    .ReadAsStreamAsync();

var result = await JsonSerializer
    .DeserializeAsync<ChatResponse>(
        stream, options);
TEMA 4

Streaming en Tiempo Real

Los LLMs generan texto token por token. El streaming permite mostrar la respuesta a medida que se genera, mejorando drásticamente la experiencia de usuario.

¿Cómo funciona el streaming?

  1. 1 El cliente envía "stream": true en el payload JSON.
  2. 2 El servidor responde con Transfer-Encoding: chunked y mantiene la conexión abierta.
  3. 3 Cada chunk es un objeto JSON independiente con un token o fragmento de texto.
  4. 4 El último chunk contiene "done": true y metadatos de la generación.

Claves del Streaming en .NET

  • ✓ GetStreamAsync() - Obtiene el stream HTTP sin bufferizar.
  • ✓ StreamReader - Lectura línea por línea del stream.
  • ✓ IAsyncEnumerable<T> - Patrón moderno para streams tipados.
  • ✓ JsonSerializer.DeserializeAsyncEnumerable - Deserialización incremental.

Implementación Completa de Streaming

AiService.cs - Streaming con IAsyncEnumerable 
public async IAsyncEnumerable<string> StreamChatAsync(
    ChatRequest request,
    [EnumeratorCancellation] CancellationToken cancellationToken = default)
{
    // Configurar request para streaming
    request = request with { Stream = true };

    // Obtener el stream HTTP sin bufferizar
    using var response = await _client.PostAsJsonAsync(
        "/api/chat", request, cancellationToken);
    
    response.EnsureSuccessStatusCode();

    // Leer el stream línea por línea
    using var stream = await response.Content.ReadAsStreamAsync(cancellationToken);
    using var reader = new StreamReader(stream);

    string? line;
    while ((line = await reader.ReadLineAsync()) != null)
    {
        if (string.IsNullOrWhiteSpace(line)) continue;

        // Deserializar cada chunk JSON
        var chunk = JsonSerializer.Deserialize<ChatResponse>(line);
        
        if (chunk?.Message?.Content != null)
        {
            yield return chunk.Message.Content;
        }

        if (chunk?.Done == true) yield break;
    }
}

// Consumo en la aplicación
await foreach (var token in aiService.StreamChatAsync(request))
{
    Console.Write(token); // Renderizado en tiempo real
}

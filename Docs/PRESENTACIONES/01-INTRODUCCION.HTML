Objetivos de Aprendizaje

¿Qué lograrás en esta capacitación?

Al finalizar los 2 encuentros, serás capaz de integrar modelos de IA open source en aplicaciones .NET enterprise sin depender de servicios en la nube ni wrappers de terceros.

Servidores Locales

Despliega y gestiona Ollama, LM Studio y llama.cpp como proveedores de inferencia local.

C# Puro y APIs REST

Comunicación directa vía HttpClient y System.Text.Json. Sin OllamaSharp ni Microsoft.Extensions.AI.

RAG con Lógica .NET

Implementa Retrieval-Augmented Generation con chunking algorítmico y filtros híbridos en C#.

Streaming en Tiempo Real

Manejo de streams HTTP con IAsyncEnumerable y lectura de tokens en tiempo real desde .NET.

Model Context Protocol

Integra MCP para que los LLMs invoquen funciones de C# de forma autónoma y tipada.

Seguridad y Producción

Datos sensibles nunca salen de tu infraestructura. Validación de esquemas JSON y manejo de errores.

Temario Completo

8 horas divididas en 2 encuentros

Cada módulo es un SCO (Sharable Content Object) independiente, compatible con cualquier LMS que soporte SCORM 1.2.

Encuentro 1 · Horas 1-2

Fundamentos y Entornos Locales

  • 1 IA Open Source: Ecosistema Hugging Face, modelos open source vs. propietarios.
  • 2 Cuantización (GGUF): Q4_K_M vs Q8_0. Regla: 1B parámetros ≈ 0.7-1GB en RAM.
  • 3 Destilación: Phi-3, Llama-3-8B, Qwen2.5 heredan capacidades de modelos masivos.
  • 4 Despliegue: Ollama (localhost:11434) y LM Studio (localhost:1234/v1). Descarga de modelos.
Encuentro 1 · Horas 3-4

Comunicación HTTPS Pura en .NET

  • 1 Anatomía de APIs: Endpoints /api/generate, /api/chat, /api/embeddings y /v1/chat/completions.
  • 2 HttpClient en .NET: IHttpClientFactory, evitar Socket Exhaustion, configuración de timeouts.
  • 3 Serialización: System.Text.Json, records tipados, manejo de payloads JSON.
  • 4 Streaming: GetStreamAsync(), lectura de tokens en tiempo real con StreamReader.
Encuentro 2 · Horas 5-6

RAG y Procesamiento Algorítmico

  • 1 Pipeline RAG: Ingesta → Chunking → Embedding → Almacenamiento → Recuperación → Generación.
  • 2 Chunking en C#: Segmentación algorítmica por caracteres, tokens o saltos de línea.
  • 3 Embeddings locales: nomic-embed-text, bge-m3 vía API REST de Ollama.
  • 4 Filtrado híbrido: Similitud coseno en C# + filtros LINQ por metadatos (fecha, categoría).
Encuentro 2 · Horas 7-8

Salida Estructurada y MCP

  • 1 JSON Mode: Forzar respuestas tipadas con format: "json" y deserialización con System.Text.Json.
  • 2 Minimal API: Endpoint .NET que recibe pregunta, recupera contexto y devuelve respuesta estructurada.
  • 3 MCP (Model Context Protocol): Estándar abierto de Anthropic para conectar LLMs con herramientas.
  • 4 Tools en C#: JSON-RPC sobre stdio/SSE. El LLM invoca funciones de C# basándose en el contexto.
Deep Dive

RAG con Procesamiento Algorítmico en C#

No delegues toda la lógica al LLM. En esta capacitación aprenderás a usar C# para pre-procesar documentos, aplicar filtros metabólicos y post-procesar respuestas, garantizando resultados confiables en producción.

Chunking Algorítmico

División de texto por tokens o caracteres en C# puro, sin dependencias externas.

Similitud de Coseno en C#

Cálculo vectorial nativo con LINQ y arrays de floats para ranking de documentos.

Validación de Esquemas JSON

Deserialización robusta con records y validación estricta para evitar fallos en producción.

Filosofía del Curso

C# para la lógica, Open Source para la inferencia. Toda la programación de aplicación se realiza exclusivamente en .NET. Python solo se utiliza en los binarios nativos de los servidores locales (Ollama, LM Studio), nunca en tu código de aplicación. La comunicación es 100% vía APIs REST/HTTPS usando System.Net.Http.
